# Starry Passage · 元宇宙

《流光 · Starry Passage》的网页试玩版。玩家可以在星月夜村庄中自由探索，把币圈情报站的 Alpha 空投与稳定性数据变成游戏内的空间体验。

## 在线试玩

- 最新版游戏：https://starry-passage-metaverse.yjrp9pq529.chatgpt.site/
- 主站入口：https://yuequan123.com/starry-passage
- 旧 GitHub Pages 地址仅保留为历史版本，不再作为主站入口。

## 当前版本 · v0.2.1

- 保留 Alpha 教堂、今日活动、预告与稳定性面板。
- 已移除社区大厅、社区墙面屏、C 快捷入口及相关公开帖子请求。
- 主站入口统一命名为“元宇宙”。
- 手机端支持触屏入口与横屏游玩。

## 数据节奏

- Alpha 活动：每 17 秒读取一次币圈情报站快照。
- 稳定性：每 5 秒读取一次币圈情报站快照。
- 游戏不直接访问 Binance，不保存网站密码、Cookie、登录令牌或钱包信息。
- 各数据源独立运行；接口异常时保留最后一次成功数据并自动重试。

## 发布说明

最新版由 Godot 4.3 导出为 Web，并通过独立静态站点提供。大型 PCK/WASM 资源会分块流式加载，以避免单文件托管上限。GitHub 仓库保留发布流程和版本说明。
